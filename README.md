## Überblick über die Sprache und die .NET-Plattform

C# ist eine Programmiersprache, die im Februar 2002 offiziell zusammen mit der .NET 1.0-Plattform von Microsoft veröffentlicht wurde, mit der sie untrennbar verbunden ist. C# benötigt diese Laufzeitumgebung, um zu funktionieren, die eine sehr umfangreiche Sammlung von Klassen bereitstellt.

Auf den ersten Blick ist die .NET-Plattform eine Laufzeitumgebung, die einer Java-Virtual-Machine ähnelt, mit einigen bemerkenswerten Unterschieden:

**Plattformübergreifend**: Während Java von Anfang an auf verschiedenen Betriebssystemen lief, war .NET ursprünglich auf Windows beschränkt. Das Projekt **[Mono](http://www.mono-project.com)** ermöglicht es nun jedoch, .NET auf Systemen wie Unix und Linux zu nutzen.


**Mehrsprachig**: Die .NET-Plattform ermöglicht die Ausführung von Programmen, die in verschiedenen Sprachen geschrieben sind, sofern deren Compiler IL-Code (Intermediate Language) erzeugt. Alle .NET-Klassen stehen für diese Sprachen zur Verfügung, was die Unterschiede zwischen ihnen verwischt; die Wahl einer .NET-Sprache wird somit eher zu einer Frage der Präferenz als der Leistung.





## Entwicklung der Sprache

Im Jahr 2002 (C# 1.0) ähnelte die Sprache stark Java, was den Wechsel zwischen den beiden Umgebungen erleichterte. Seitdem haben sich die spezifischen Merkmale der jeweiligen Sprachen deutlicher voneinander abgegrenzt.

Mit der Einführung von C# 3.0 und dem .NET-Framework 3.5 kamen zahlreiche neue Funktionen hinzu, von denen die bedeutendste wahrscheinlich **LINQ** (Language INtegrated Query) ist. LINQ ermöglicht es, Arrays, Listen, Datenbanken oder XML-Dateien auf einheitliche Weise (ähnlich wie bei SQL) abzufragen.

>
